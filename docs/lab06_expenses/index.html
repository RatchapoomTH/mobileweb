บริหารรายรับและรายจ่ายของคุณอย่างมีประสิทธิภาพ

📋 เกี่ยวกับเว็บแอปนี้

เว็บแอป Lab06-Expense เป็นเครื่องมือที่ออกแบบมาเพื่อช่วยให้คุณจัดการการเงินส่วนบุคคลอย่างง่ายและมีประสิทธิภาพ บันทึกรายรับและรายจ่ายของคุณ และดูภาพรวมของสถานะการเงินตลอดเวลา

✨ ฟีเจอร์หลัก

💵 บันทึกรายการ

  • เพิ่มรายรับและรายจ่าย อย่างง่ายดาย
  • ระบุคำอธิบายละเอียด
  • บันทึกจำนวนเงินได้ทันที

🔧 จัดการข้อมูล

  • แยกตามประเภท (อาหาร เดินทาง ฯลฯ)
  • ลบรายการได้
  • แก้ไขรายการได้

📊 ดูสรุปผล

  • สรุปยอดรวมทั้งหมด
  • แสดงผลในรูปแบบกราฟ
  • วิเคราะห์รูปแบบการใช้จ่าย
